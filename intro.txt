IRFSA 射频信号智能分析仪
答辩介绍与项目优势提纲

一、项目一句话介绍

IRFSA 是一套面向宽带无线电信号的端到端智能分析系统。系统以AD9361 SDR设备为前端，完成信号产生、接收、IQ 数据传输和频谱显示；以自研的轻量级多尺度 IQ 调制识别模型为核心，完成 18 类调制方式识别；最终将 FPGA、PS、ZG330 NPU 和桌面软件整合为可实时运行、可观测、可录制、可评估的射频信号智能分析仪。

可以这样开场：
“我们的项目不是单独训练一个分类模型，而是构建了一条从射频采集、数据校验、信号预处理、神经网络推理到结果显示的完整链路。它兼顾了射频覆盖范围、实时处理能力、模型识别准确率和工程可部署性，能够把实验室算法真正落到 FPGA、边缘 NPU 和实际采集数据上。”

二、项目实现的主要功能

1. 射频信号产生与接收

- 基于 FMC AD9361 和 KU5P FPGA 实现射频收发。
- TX 本振覆盖 300 MHz～6 GHz，TX1 基带带宽覆盖 0.005～10 MHz。
- 支持 AM、FM、ASK、FSK、PSK、QAM 等调制信号；TX1 支持多种阶数，TX2 可产生带限噪声。
- RX 支持手动增益、慢速 AGC 和快速 AGC，支持 1 MSPS 抽取输出和 25 MSPS 原始 IQ 输出。
- 支持通过 UART 配置发射参数，通过 UDP 配置接收参数并传输 IQ 数据。

2. IQ 数据链路与数据完整性保障

- FPGA 侧完成 AD9361 初始化、频率规划、调谐、校准、LVDS IQ 装配、FIR 抽取和 UDP 封装。
- 采用 RFCT 控制帧和 RFIQ 数据帧，带有来源校验、会话号、元数据和 CRC 校验。
- 主机端将 IQ 数据重组成连续窗口，保存为 .iq、.index.bin 和 .json 三件套，能够追溯采样率、频率、增益、标签、窗口位置和采集状态。
- 对旧会话、错误来源、元数据不匹配、CRC 错误、全零窗口和 ADC 饱和窗口进行过滤，保证送入模型的数据可用。

3. 实时观测与分析软件

RF Studio 提供 Windows 图形化操作界面，支持：

- TX/RX 参数设置、设备连接、状态读取和发射控制；
- IQ 波形、星座图、功率谱和瀑布图实时观测；
- 普通录制、训练数据采集和批量参数扫描；
- ONNX 模型实时识别和录制目录离线评估；
- 通过本机 TCP 命令接口进行脚本化控制，便于自动化测试和演示。

4. 边缘部署与本地显示

正式运行工程 FPAI_30T 将功能下沉到板端：

- FPGA 侧完成 IQ 接收、1024 点 FFT、功率谱处理和 720p HDMI 显示；
- PS 端负责 RFCT/RFIQ 通信、窗口调度、结果发布和显示提交；
- C++ 推理工作程序调用 iCraft Host 和 ZG330 后端完成模型推理；
- 通过 JSON/RAW 模型、预处理配置和标签文件保证模型与硬件输入输出契约一致。

三、核心模型与技术创新

1. 自研轻量化多尺度 IQ 模型

模型名称为 correlation_multiscale，输入为 1 MSPS、1024 点复数 IQ 窗口，数据形状为 (N, 2, 1024)。模型直接处理 I/Q 两路实数信号，不依赖复杂的手工特征提取，适合 ONNX Runtime 和 ZG330 NPU 部署。

当前网络由两部分组成：

- 原始 IQ 分支：采用多尺度残差 CNN，在时间方向使用 3、15、31 点卷积并行提取短时、局部和较长时间范围的波形特征；通过残差连接稳定训练，通过延后池化保留更多时序细节。
- 延迟复相关分支：对 I/Q 信号计算 1、2、4 点延迟复相关，显式提取幅度变化和相位变化之间的关联，再通过小型残差 CNN 对结果进行修正。

延迟复相关避免了直接使用 atan2 带来的相位跳变问题，同时保留调制信号中的幅度、频率和相位变化信息。按当前源码结构估算，模型约 16.5 万个可训练参数，答辩中可概括为“约 0.17M 参数的轻量化自研模型”；如果需要做严格横向对比，建议在最终训练环境中再次统计参数量。

2. 为什么说模型是“高性能”和“轻量化”

- 输入直接使用 IQ 双通道，避免把信号转换成大尺寸图片，减少数据搬运和预处理开销。
- 多尺度卷积同时观察短期和长期时域结构，对 ASK、FSK、PSK、QAM、AM、FM 等不同调制特征具有统一表达能力。
- 残差结构提高特征复用能力，网络深度和参数量保持在较小规模。
- 全局平均池化将时域特征压缩为固定维度，适合批量推理和边缘 NPU 编译。
- 模型已导出为 ONNX，并完成 CPUExecutionProvider 下的导出一致性检查：最大 logit 误差约 2.29e-5，小于 0.001 的容差，测试批大小覆盖 1、2、7、16、31、128，预测结果与 PyTorch 保持一致。

推荐答辩表述：
“我们没有直接套用一个大规模视觉网络，而是根据 IQ 信号的时域结构自建了多尺度残差模型，并加入延迟复相关分支。模型规模约 0.17M 参数，在保留调制特征表达能力的同时，降低了边缘部署的存储、带宽和计算压力。”

四、极低处理延时与高实时性

1. 窗口级理论时延

模型每次处理 1024 个 IQ 点，采样率为 1 MSPS，因此一个识别窗口对应的信号时长为：

1024 / 1,000,000 = 1.024 ms

这意味着系统具备毫秒级窗口更新基础。1.024 ms 是信号窗口时长，不等同于完整端到端延时；完整延时还包括采集、UDP 传输、窗口组装、预处理、NPU 推理和显示。

2. 流水线设计

系统将采集、协议接收、信号分析、模型推理和界面显示拆分为独立任务：

- FPGA 负责高速 IQ 接收、FFT 和频谱处理；
- PS 服务负责窗口调度和结果发布；
- ZG330 NPU 负责边缘模型推理；
- RF Studio 中的接收、频谱/星座分析和 ONNX 推理运行在后台线程或独立进程，避免阻塞界面主线程；
- 连续窗口可以采用 1、2、4、8 或 16 帧 logits 平均，提高结果稳定性。

桌面软件当前按约 0.25 秒提交一次实时识别任务，这是为了控制 UI 更新和任务排队，不应表述为模型本身的端到端处理延时。答辩时可以说：
“系统采用窗口化流水线和异步推理，算法窗口仅 1.024 ms；正式板端由 FPGA、PS 和 NPU 并行协作，满足连续数据流的实时处理要求。最终端到端延时应以目标板实测结果为准。”

五、宽带信号处理能力

项目的“宽带”体现在射频前端、采样链路和数字处理三个层面：

- 射频覆盖：TX 本振 300 MHz～6 GHz；
- 发射带宽：TX1 基带带宽 0.005～10 MHz；
- 接收采样：支持 25 MSPS 原始 IQ，适合观察较宽频带；
- 低速识别：支持 FIR 抽取到 1 MSPS，提供稳定的 1024 点窗口供模型识别；
- FPGA 侧完成 FFT 和功率谱处理，既能显示宽带频谱，又能抽取窗口进入智能识别链路。

需要区分两个概念：射频前端和接收链路具有宽带能力，而当前 18 类模型的识别输入契约是 1 MSPS、1024 点窗口。也就是说，系统可以先对宽带信号进行接收和频谱分析，再根据目标频段抽取适合模型的 IQ 窗口进行调制识别。

25 MSPS 原始 IQ 数据量约为 100 MB/s，需要千兆网络和足够快的磁盘；因此工程中将 25 MSPS 主要用于宽带观测，将 1 MSPS 作为模型识别和训练采集的标准路径。

六、低信噪比识别能力

1. 针对低 SNR 的设计

- 发射端支持 TX1 内部数字 SNR -10～20 dB，并可叠加可控噪声；
- 训练过程启用了分档 SNR 加权损失，对不同 SNR 区间进行差异化加权，提升噪声条件样本对训练的影响；
- 模型使用多尺度时域特征和延迟复相关特征，减少单一瞬时特征在噪声下失效的风险；
- 通过连续窗口 logits 平均进行多帧融合，降低单窗随机误判；
- 每窗 RMS 归一化，减弱接收增益和幅度变化对分类的影响；
- 对全零、ADC 饱和、CRC 错误和不连续窗口进行剔除，避免坏数据影响判决。

2. 当前资料能够支撑的准确率表述

随附模型卡记录的 18 类模型验证集准确率为 88.2053%，复用测试集准确率为 88.0441%。该测试集标记为 reused，且模型卡注明 received SNR/SINR 未直接测量，因此这两个数字应表述为“当前模型的总体验证结果”，不能直接说成“实测低信噪比准确率”。

推荐答辩表述：
“针对低信噪比场景，我们采用 SNR 加权训练、每窗 RMS 归一化、多尺度特征和多帧 logits 融合，提高模型在噪声条件下的稳定性。当前模型卡给出的 18 类总体验证准确率约为 88.2%。低 SNR 分段准确率需要在独立、带实测接收 SNR/SINR 的测试集上单独统计，项目具备批量采集、标签保存和按帧数评估的完整工具链。”

如果答辩老师追问“最低 SNR 下是多少”，建议回答：
“目前发布资料只有发射端内部 SNR 设置，接收端实测 SNR/SINR 尚未形成独立标定报告，因此我们不把 TX 设置值直接等同于接收 SNR。后续可以按 SNR 档位分别采集测试集，输出每档准确率、混淆矩阵和多帧融合曲线。”

七、识别类别与模型边界

当前桌面 ONNX 模型和 Python 模型覆盖 18 类：

16ASK、16FSK、16QAM、2ASK、2FSK、2PSK、4ASK、4FSK、4PSK、64QAM、8ASK、8FSK、8PSK、AM-DSB-SC、AM-DSB-WC、AM-SSB-SC、AM-SSB-WC、FM。

模型是闭集分类器，当前随附模型不包含 16PSK 和 256QAM。对于训练类别之外的信号，模型仍可能输出 18 个已知类别中的一个，因此工程展示中应说明类别范围，不能把闭集输出直接解释为开放集检测结果。

八、项目优势总结

1. 软硬件协同：从 AD9361、FPGA RTL、UDP/UART 协议到桌面软件、ONNX 和 ZG330 推理全部打通，形成完整系统。
2. 自研模型：围绕 IQ 信号特点设计多尺度残差和延迟复相关结构，不依赖通用图像模型。
3. 轻量部署：模型约 0.17M 参数，输入固定、算子规则，适合 ONNX 和边缘 NPU 编译。
4. 实时处理：1024 点窗口对应 1.024 ms 信号时长，采集、FFT、窗口调度和推理采用流水线架构。
5. 宽带兼容：300 MHz～6 GHz 射频覆盖、最高 25 MSPS 原始采样，同时提供 1 MSPS 模型识别路径。
6. 数据可追溯：IQ、窗口索引、JSON 配置和 CRC 校验共同保证数据可复现、可审计。
7. 低信噪比适应：SNR 加权训练、RMS 归一化、多尺度/相关特征和多帧融合共同增强噪声环境下的判决稳定性。
8. 工程可验证：支持在线识别、离线评估、混淆矩阵、按 1/2/4/8 帧统计和批量采集，不只展示单次 Demo。
9. 可扩展：RFCT/RFIQ 协议、模型说明文件、预处理契约和模型加载配置相互独立，便于更换模型、扩展调制类别和迁移硬件平台。

九、两分钟答辩稿

“本项目是一套射频信号智能分析仪，目标是把射频采集、数字信号处理和人工智能识别集成到一个可实时运行的工程系统中。前端采用 FMC AD9361 和 KU5P FPGA，支持 300 MHz 到 6 GHz 的本振范围、0.005 到 10 MHz 的发射基带带宽，以及最高 25 MSPS 的接收 IQ 采样。系统通过 UART 和 UDP 完成射频控制和 IQ 传输，并利用 RFCT/RFIQ 协议、会话号、元数据和 CRC 机制保证数据完整性。

识别部分采用我们自建的 correlation_multiscale 轻量模型。模型输入是 1 MSPS、1024 点的 I/Q 窗口，网络使用 3、15、31 点多尺度卷积提取不同时间范围的特征，同时构造 1、2、4 点延迟复相关，显式建模幅度和相位变化。模型约 0.17M 参数，已经导出到 ONNX，并进一步编译到 ZG330 NPU，适合边缘部署。当前模型覆盖 18 类 AM、FM、ASK、FSK、PSK 和 QAM 调制，模型卡记录的总体验证准确率约为 88.2%。

在实时性方面，1024 点窗口在 1 MSPS 下只对应 1.024 ms 的信号时长。正式运行工程由 FPGA 完成 FFT 和频谱处理，PS 负责窗口调度，ZG330 负责推理，桌面端则用后台线程和独立进程避免界面阻塞。针对低信噪比，我们使用 SNR 加权训练、RMS 归一化和连续多帧 logits 融合来提高稳定性。项目的优势在于软硬件链路完整、模型轻量、射频覆盖宽、数据可追溯，并且具备在线识别和离线评估能力，能够从算法 Demo 走到板端实际运行。”

十、常见追问的简短回答

问：项目最大的创新是什么？
答：创新点是面向 IQ 信号自建轻量模型，并将延迟复相关、多尺度时域卷积和 FPGA/PS/NPU 流水线结合起来，形成完整的端到端实现。

问：为什么不用大模型？
答：射频边缘设备更关注吞吐、时延、功耗和可部署性。当前模型约 0.17M 参数，固定输入、算子简单，更适合 ONNX 和 ZG330，同时保留了调制识别所需的时域特征。

问：模型是不是只识别图片？
答：不是。模型直接输入两路实数 IQ，形状为 (N,2,1024)，不需要把信号转换为时频图。

问：实时性如何证明？
答：单个识别窗口包含 1024 个采样点，在 1 MSPS 下对应 1.024 ms；系统采用 FPGA、PS、NPU 分工和异步流水线。完整端到端延时应在目标板上用时间戳实测，并分别报告采集、传输、推理和显示耗时。

问：低信噪比准确率是多少？
答：当前资料能直接支撑的是 18 类总体验证准确率 88.2053%，复用测试集 88.0441%；低 SNR 分段准确率需要基于实测接收 SNR/SINR 的独立测试集统计，不能把 TX 内部 SNR 设置值直接当作接收 SNR。

问：宽带和模型的 1 MSPS 是否矛盾？
答：不矛盾。25 MSPS 和 300 MHz～6 GHz 覆盖体现前端和采集链路的宽带能力；模型识别需要稳定、统一的 1 MSPS 窗口，系统先完成宽带接收和频谱分析，再抽取目标信号进行识别。

问：模型能识别所有调制吗？
答：当前模型是 18 类闭集分类器，不包含 16PSK 和 256QAM。后续可以通过扩充采集数据、增加类别并重新训练来扩展。

十一、答辩时应避免的过度表述

- 不要把“1.024 ms 窗口时长”说成“端到端延时 1.024 ms”。
- 不要把 RF Studio 的 0.25 秒实时任务提交周期说成模型推理耗时。
- 不要把 TX1 内部数字 SNR 当作接收端实测 SNR 或 SINR。
- 不要把 88.2% 总体验证准确率说成所有低 SNR 档位都达到 88.2%。
- 不要把闭集分类器说成能够识别未知调制或完成开放集检测。
- 不要把 25 MSPS 原始采样直接等同于模型的 25 MHz 有效识别带宽；模型输入契约是 1 MSPS。
