# RF Studio

面向 KU5P / AD9361 的射频控制与 IQ 分析软件，支持双路发射控制、RX1 观测与录制、训练数据采集、批量采集和 ONNX 调制识别。

## 启动

Windows 下双击 `KU5P_Radio_Studio.exe` 或 `Start_KU5P.bat`。可执行程序无需另行安装 Python。

需要 Agent 或脚本控制时，在软件控制台输入 `serve`，或使用以下方式启动：

```powershell
Set-Location 'D:\e-project\IRFSA_release\RF_studio'
.\KU5P_Radio_Studio.exe --serve 47100
```

使用源码运行时，需要 Python 3.10+、Tkinter、NumPy 和 ONNX Runtime。串口依赖随附于 `vendor`。

```powershell
python -m pip install numpy onnxruntime
python -B app.py
```

## 连接设备

1. 连接串口，在界面选择实际 COM 口，使用 115200 / 8N1，点击连接 UART。
2. 连接板卡网口，设置 PC 网卡地址和界面中的本机 / 板端地址。默认分别为 `192.168.10.1` 和 `192.168.10.2`。
3. 点击连接网口 RX，连接后可设置接收参数、开启观测或录制。

TX 控制走 UART；RX 控制走 UDP 40001，IQ 数据走 UDP 40000。串口连接和网口连接相互独立。防火墙需允许程序访问相应网络端口。

## 基本操作

在 TX1、TX2、RX1 参数页设置参数后，点击 `upload`。TX 开关和 RX 观测开关分别操作。

| 功能 | 操作说明 |
|---|---|
| TX1 | 选择调制方式、本振、基带带宽、频偏、衰减及内部噪声参数 |
| TX2 | 设置带限噪声的频段与衰减，单独控制开关 |
| RX1 | 设置接收本振、模拟带宽、增益模式及输出采样率 |
| 同窗观测 | 查看 IQ 波形、星座、功率谱及瀑布图；观测本身不保存 IQ 文件 |
| 普通录制 | 在录制页设置目录、时长和文件名后开始录制 |
| 训练采集 | 以 TX1 配置读回作为标签，锁定采集过程中的相关参数 |
| 批量采集 | 在训练模式页编辑任务段、扫描档位和重复次数，检查后开始 |
| 模型测试 | 加载模型，对实时 IQ 识别或对录制目录执行离线评估 |

界面频率单位为 MHz，增益与衰减单位为 dB。TX1 的基带带宽 `B` 为单边带宽，频偏为载波相对 TX 本振的位置。双边带信号占用约 `2B`，SSB 信号占用约 `B`；板端需支持与界面一致的带宽语义，出现兼容性提示时按提示处理。

RX 支持 1 MSPS 和 25 MSPS 输出。1 MSPS 适合模型识别与训练采集；25 MSPS 原始 IQ 数据量约为 100 MB/s，需要相应的网络和磁盘吞吐能力。

PC 端 RX 滤波器支持低通、高通、带通和带阻，作用于观测及录制数据，仅支持 1 MSPS。录制期间保持参数锁定。

## 录制与任务文件

一次录制由同名的三个文件组成，应放在同一目录中使用：

- `.iq`：小端 int16，按 I、Q 交替排列。
- `.index.bin`：窗口索引、采样位置、标志和 CRC。
- `.json`：采样配置、标签、统计及结束状态。

默认普通录制目录为 `captures`，训练目录为 `captures/training`。批量任务可保存和导入 `campaign_*.json`，通过训练页继续未完成的采集。

程序在使用时保存 `settings.json`、`logs`、`state` 和评估报告。`state` 中的编号数据库由程序维护，使用期间不要手动重置。

## 模型识别

随附模型为 `model/fullscale_v6_18class.onnx`，配套说明为同名 `.model.json`。模型要求 1 MSPS 输入，支持 18 类调制，不包含 16PSK 和 256QAM。

在“模型测试”页选择模型，开启 RX1 同窗观测后勾选实时识别；离线评估则选择训练采集目录并点击“开始评估”。具体类别、数据约定及报告说明见 [model_test.md](model_test.md)。

## 离线演示

选择“离线演示”，依次连接模拟 UART 和模拟 RX，可体验参数设置、观测及录制。演示数据使用 `DEMO_` 文件名前缀，并在元数据中标明模拟来源，仅用于操作与流程演示。

## 停止操作

使用紧急停止关闭 TX1、TX2 并停止本软件的 RX 会话，随后查看状态和日志中的结果。关闭窗口或断开串口不会自动关闭板端 TX。`train stop` 只停止批量采集，不能代替紧急停止。
